# SBCE Control

Browser console for the Avaya SBCE manager. Inventory, certificate renewal, CSR handoff, snapshots, and reporting. SBCE API calls in this build are simulated so the workflows can be exercised without a live controller.

Branding matches [Gage Technologies](https://gagetech.com/): Plus Jakarta Sans, slate `#17262D`, copper `#C16B29`.

```bash
npm install
npm run dev
```

Sign in with **Continue with Entra ID**, or locally:

- Admin: `admin` / `harbor-admin`
- Operator: `operator` / `lookout`
